# Instructor Answer Key - Lesson 19: Active Directory

Do not distribute this file before the assessment closes. Accept defensible scenario and theory answers when students support their reasoning with accurate security concepts, evidence, and business context.

### Answer Key

1. **A.** Forest-wide schema, configuration, trusts, and privileged roles make the forest the primary traditional boundary.
2. **A.** Trust permits authentication recognition; target-resource authorization is still required.
3. **A.** Security groups are security principals and can appear in ACLs and tokens.
4. **A.** OUs organize objects, scope delegation, and receive GPO links.
5. **A.** A TGT is presented to the Ticket-Granting Service to request service tickets.
6. **A.** The SPN identifies the service principal for Kerberos ticket issuance.
7. **A.** Relay forwards captured challenge-response authentication to another service that accepts it.
8. **A.** Simple credentials require protected transport because otherwise credential confidentiality is at risk.
9. **A.** LSDOU summarizes Local, Site, Domain, and OU policy processing.
10. **A.** Access review is a recurring people-driven operational process.
