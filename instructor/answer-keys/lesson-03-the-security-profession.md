# Instructor Answer Key - Lesson 3: The Security Profession

Do not distribute this file before the assessment closes. Accept defensible scenario and theory answers when students support their reasoning with accurate security concepts, evidence, and business context.

### Answer Key

1. **A.** A SOC analyst commonly monitors, triages, documents, and escalates security alerts.
2. **B.** Security+ is positioned as a broad foundational certification for early cybersecurity learners.
3. **A.** A vulnerability management analyst prioritizes scan findings and tracks remediation.
4. **A.** Exam objectives and certification versions change, so students should verify the current version before registering.
5. **B.** Professional incident notes should be evidence-based and include clear facts, timestamps, and uncertainty where needed.
6. **A.** A security administrator commonly manages security controls and security tool configuration.
7. **A.** A systems administrator manages operating systems, services, patches, accounts, and backups.
8. **A.** OSCP is associated with hands-on penetration testing skill.
9. **A.** Continuous learning is required because threats, tools, platforms, and best practices change.
10. **B.** A documented lab with scope, steps, evidence, findings, and lessons learned demonstrates practical beginner skill.

Short answer responses should connect role responsibilities to practical enterprise work and use evidence-based reasoning.
