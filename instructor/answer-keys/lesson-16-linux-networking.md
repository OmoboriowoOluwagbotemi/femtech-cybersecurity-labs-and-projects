### Answer Key

1. **A.** The `ip` suite is the modern interface, address, neighbor, and route administration tool.
2. **A.** `0.0.0.0` normally represents all assigned local IPv4 addresses for binding; firewall and routing still control reachability.
3. **A.** `ss` is the modern, efficient socket-inspection tool in `iproute2`.
4. **A.** `NXDOMAIN` indicates that the queried DNS name does not exist according to the response.
5. **A.** `--insecure` bypasses certificate trust and hostname verification, weakening server authentication.
6. **A.** Local forwarding creates the requested listener on the SSH client side.
7. **A.** Dynamic forwarding creates a SOCKS proxy for compatible application traffic.
8. **A.** Effective Samba access depends on network, protocol, share, identity, and filesystem controls.
9. **A.** `testparm` parses and validates Samba configuration before deployment.
10. **A.** Access review is performed through a people-driven operational process.
