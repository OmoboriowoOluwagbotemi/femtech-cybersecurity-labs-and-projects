# Instructor Answer Key - Lesson 12: Users, Groups and Permissions

Do not distribute this file before the assessment closes. Accept defensible scenario and theory answers when students support their reasoning with accurate security concepts, evidence, and business context.

### Answer Key

1. **A.** The kernel uses the numeric UID for user identity and access decisions.
2. **A.** `-aG` appends the listed supplementary group instead of replacing the existing supplementary set.
3. **A.** The `user:group` form changes both ownership fields.
4. **A.** setgid on a directory makes new entries inherit its group, supporting controlled collaboration.
5. **A.** The sticky bit limits deletion and rename of entries in a shared writable directory.
6. **A.** The ACL mask caps effective permissions for named users, named groups, and the owning group class.
7. **A.** `visudo` locks and validates sudoers syntax before installation.
8. **A.** Locking password authentication does not automatically remove sessions, keys, jobs, or every authentication path.
9. **A.** Any UID `0` identity has root-equivalent kernel identity.
10. **A.** A periodic access review is performed through operational process.
