# Instructor Answer Key - Lesson 14: Linux Hardening

Do not distribute this file before the assessment closes. Accept defensible scenario and theory answers when students support their reasoning with accurate security concepts, evidence, and business context.

### Answer Key

1. **A.** A baseline is the organization's approved minimum configuration for a defined system class.
2. **A.** `sshd -t` checks server-configuration syntax before reload or restart.
3. **A.** Alternative access and recovery must be validated first to prevent administrative lockout.
4. **A.** The rule establishes default inbound denial, while explicit allows and state handling define exceptions.
5. **A.** A jail combines event matching, thresholds, time windows, ban duration, and response actions.
6. **A.** `ausearch` queries Linux Audit records by fields, messages, keys, and time.
7. **A.** Broad rules can overwhelm storage and analysis and may affect performance.
8. **A.** Drift is a departure from the approved configuration state.
9. **A.** A governed exception records accountability, risk, alternatives, and a future review point.
10. **A.** Validation is a people-driven operational procedure confirming security and business behavior.
