# Instructor Answer Key - Lesson 22: Remote Access and VPN

Do not distribute this file before the assessment closes. Accept defensible scenario and theory answers when students support their reasoning with accurate security concepts, evidence, and business context.

### Answer Key

1. **A.** A VPN provides a protected logical path over another network.
2. **A.** Site-to-site VPNs commonly connect network gateways and prefixes.
3. **A.** Split tunneling sends only selected traffic through the VPN.
4. **A.** Zero Trust requires explicit, contextual, least-privileged access rather than location-based implicit trust.
5. **A.** Public RDP creates a directly reachable authentication and control surface.
6. **A.** NLA authenticates before allocating a full remote desktop session.
7. **A.** Identity alone does not establish endpoint security state.
8. **A.** Governed vendor access is accountable, temporary, scoped, strongly authenticated, and monitored.
9. **A.** Compromise can persist through other identity, endpoint, and cloud mechanisms.
10. **A.** Review is performed through a people-driven operational process.
