# Instructor Answer Key - Lesson 17: Windows Fundamentals

Do not distribute this file before the assessment closes. Accept defensible scenario and theory answers when students support their reasoning with accurate security concepts, evidence, and business context.

### Answer Key

1. **A.** Windows uses SIDs to identify principals independently of display names.
2. **A.** An access token carries the identity, groups, privileges, integrity, and restrictions used for access checks.
3. **A.** `HKLM` represents system-wide machine configuration.
4. **A.** The Service Control Manager maintains service definitions and operational control.
5. **A.** Names can be imitated; path, signature, hash, ancestry, identity, and behavior provide stronger context.
6. **A.** Event 4625 generally records a failed logon under the Security auditing provider.
7. **A.** Event identifiers are defined by providers and interpreted within their channel and schema.
8. **A.** PowerShell pipelines pass .NET objects retaining properties and types.
9. **A.** Execution policy helps prevent accidental script execution but is not designed as a determined-attacker boundary.
10. **A.** A review is performed through a people-driven operational process.
