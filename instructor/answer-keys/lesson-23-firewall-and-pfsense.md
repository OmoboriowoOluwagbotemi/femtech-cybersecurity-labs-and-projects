# Instructor Answer Key - Lesson 23: Firewall and pfSense

Do not distribute this file before the assessment closes. Accept defensible scenario and theory answers when students support their reasoning with accurate security concepts, evidence, and business context.

### Answer Key

1. **A.** Stateful filtering tracks connection context and related return traffic.
2. **A.** Default deny permits only traffic matched by explicit allow policy.
3. **A.** Source NAT commonly translates private internal sources for upstream communication.
4. **A.** Port forwarding changes inbound destination details so traffic reaches a selected internal service.
5. **A.** pfSense interface rules generally evaluate packets arriving on that interface.
6. **A.** Top-down first-match behavior makes ordering part of policy.
7. **A.** A previously created state can continue independently of later rule changes.
8. **A.** A DMZ limits exposed-service access to internal networks.
9. **A.** Ownership and expiry prevent unmanaged permanent access.
10. **A.** Rule review is a people-driven operational procedure.
